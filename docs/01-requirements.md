# 01 - 需求（Requirements）

## 用户与目标

- **用户**：小影校园的员工（提问方）与知识库运营同学。
- **目标**：帮助员工找到**制度或产品问题的可靠答案**——每个结论都有文档依据与逐字引用；文档之间有冲突时如实列出并请求确认，而不是擅自选一个；知识库没有的资料如实说缺口。
- **Agent 的定位**：企业知识问答助手，不是制度的裁决者。

## 输入与材料

| 材料 | 内容 | 来源 |
| --- | --- | --- |
| 用户请求 | 问题 `question`、可选对话历史 `history`（用于上下文追问）、故障注入 `inject` | 任务输入 JSON |
| 知识库 | 带文档 ID、版本、日期的合成 FAQ / 制度文档（D01–D05） | `data/docs.json` |

可用的业务工具（题目指定两类，均为本地函数实现）：**文档检索**（search_docs）、**片段读取**（read_doc）。

## 交付结果

对每次提问输出（固定 JSON 结构，见 `examples/*.output.json`）：

- 回答（`answer`）——依据原文作答，或为 null
- 引用文档 ID 与原文片段（`citations`：doc_id、title、version、date、quote）
- 冲突列表与请求确认文案（`conflicts` / `pending_confirmation`）
- 资料缺口（`gaps`）
- 任务状态（`status`：answered / needs_confirmation / out_of_scope / failed / incomplete / missing_input）

**仅基于知识库原文作答，不接真实权限系统与外部检索**——引用必须来自 read_doc 读取的原文。

## 范围

**做（In Scope）**

- 单问题（可带对话历史）的知识问答流程
- ReAct 动态决策：依据检索结果选择**补充检索 / 读取原文 / 追问改写 / 如实终止**；**冲突查证**后请求确认
- 离线确定性 Mock 模型入口 + OpenAI 兼容 API 入口（双路径共用同一循环）
- CLI 运行方式、6 个验收场景、自动化测试与 Trace 记录

**不做（Out of Scope）**

- 真实文档系统 / 权限体系接入、多轮主动反问 UI、知识库写入
- 界面 / 线上部署 / 多 Agent / 生产级 Runtime
- 跨会话长期记忆（对话历史随单次请求输入）

## 成功标准

1. **6 个必须验收点全部通过**：明确答案、文档冲突、资料外问题、改写后的相似问题、上下文追问、工具失败。
2. **红线不越界（对应审核要点）**：
   - 回答必须有依据：answered 时 citations 非空，且每条 quote **逐字属于**对应文档原文——无依据回答或错误引用属于关键缺陷；
   - 冲突不擅自选答案：needs_confirmation 时 answer 为空、列出双方冲突引用并请求确认；
   - 无依据不编造：资料外/失败/未完成时 answer 为空且给出资料缺口；
   - 失败步骤不得记为成功。
3. **替换文档内容，答案与动作随之改变**：答案与冲突判定全部从读取的原文推导，不硬编码（测试直接覆盖）。
4. **真实 ReAct 循环**：模型（或 Mock 策略）基于工具观察结果调整下一步动作；Trace 中可还原每一步的工具参数、返回摘要与决策依据。
5. **步数上限**：达到上限（默认 12）时返回明确的 `incomplete` 未完成状态。
6. `python -m unittest discover -s tests -v` 全部通过（实际结果见 `examples/test-results.txt`）。

## 参考实例的对应实现

> 规则 D01 写明"报销期限 30 天"，D02 写明"15 天"，未给适用范围与优先级。问"报销期限多久"时，应列出冲突与引用，并请求确认适用制度；不能擅自回答 15 天。只检索到 D01 且无冲突时可依据 D01 回答。

- 文档冲突：见 `examples/doc-conflict.*` —— 检索命中 D01+D02 → 读取两篇原文 → 检测到 30 天 vs 15 天陈述冲突且两份文档均未说明适用范围与优先级 → `needs_confirmation`：列出双方引用与陈述值，请求确认，**answer 为空**。
- 单文档无冲突：见 `examples/normal.*`（D03 年假）与 `examples/paraphrase.*`（改写问句仍命中 D01）——依据单篇原文直接回答并逐字引用。
- 内容替换鲁棒性：测试 `test_8` 将 D01 改为 45 天并删除 D02 → 相同问题改为依据 D01 回答 45 天，与参考实例"只检索到 D01 且无冲突时可依据 D01 回答"一致。
